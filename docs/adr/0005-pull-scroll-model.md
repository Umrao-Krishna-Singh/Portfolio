# One viewport per pull; sketches get their own pull on mobile

Status: accepted (2026-10-03).

Each pull is exactly one viewport: 4 pulls on desktop (Hero, Quest I, Quest II, About+Contact), 7 on mobile (quest sketches split onto their own pulls). We rejected the denser alternative — text beside small sketches on mobile — because a 350px column cannot hold both readably, and the separate sketch pull gives the ink-reveal room to perform. Consequence: mobile progress runs I OF VII, and any new section must decide its pull count per breakpoint, not just its content.
