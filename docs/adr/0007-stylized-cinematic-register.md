# Stylized-cinematic is the look register, not photorealism

Status: accepted (2026-10-04).

The reference video guides mood — candlelit desk, unrolling scroll, burning text — but the target is a stylized cinematic 3D look that reads premium, and once the camera is inside the parchment the surface reads 2D/2.5D. Photorealism is explicitly rejected (unreachable with procedural + CC0 assets at this budget, and wrong for a portfolio that must stay legible); "childish" is the other rejected pole — no cartoon SVG flames, no gradient bars posing as fire, no bounce easing. Backup register if cinematic fails in practice: premium game-menu. Consequence: every asset and animation decision is judged by "does this read as crafted cinema", and cheap-looking shortcuts (emoji, cartoon strokes, default easing) are in scope to replace even when they work.
