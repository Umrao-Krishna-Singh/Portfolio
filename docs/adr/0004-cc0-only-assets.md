# CC0-only third-party assets

Status: accepted (2026-10-03).

Every third-party asset must be CC0/public-domain-equivalent (OFL for fonts, ISC/MIT for code). This explicitly rejects convenient sources with strings attached: Textures.com (no redistribution, no open-source derivatives) and Transparent Textures (mixed per-author licensing, no uniform grant). Chosen placeholders: ambientCG Paper002/Wood051 (CC0), Google Fonts trio (OFL), Lucide icons (ISC, notice kept). Glow, sigil, seal, and dividers are own-work SVG/CSS, so they carry no license at all. Full inventory: `.tmp/pen-runs/assets.md`.
