# Only light, no dark mode or theme switch

Status: accepted (2026-10-03).

The portfolio ships a single light parchment theme. There is no dark/light switch, and the build must resist dark-mode extensions (`darkreader-lock`, opaque paired colors — see `.tmp/pen-runs/research-dark-guard.md`). A dark theme would invert the core metaphor: ink on parchment is dark-on-light by definition, and a dark mode would turn it into chalk-on-slate, a different design entirely. A dark-mode extension ticket exists only as a guard, not a feature.
