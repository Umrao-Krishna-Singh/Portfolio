# No invented outcomes, years, or project names in placeholders

Status: accepted (2026-10-03).

Quest cards carry title, quest text, role, runes, links, and a two-line tale-so-far strip — never outcomes, metrics, years, or real project names until real projects are known. Invented numbers would calcify into lies the owner must later retract, and a portfolio caught exaggerating loses the trust it exists to build. A review pass triggers automatically once real projects are named; until then, placeholders stay visibly placeholder.
