# Camera valley: scroll-scrubbed and reversible; intro is one unbroken dolly

Status: accepted (2026-10-04).

Page top is the WIDE desk view, the middle is the pushed-in read framing, the end returns to WIDE — a valley scrubbed by scroll position, fully reversible: scroll down descends, scroll up ascends, in both directions, with no special "closing" animation at the bottom (the tome-closing ending was rejected: a website is revisited upward). The intro is one shot: ~2s wide hold, then ONE continuous dolly during which the scroll drops with a heavy damped thud-settle and unrolls — never a sequence of separate camera moves (the WIDE→MID→drop→unroll→PUSH chop was rejected because it reads as a replay when the end-mark flies the camera back). Click skips the intro. Consequence: camera state is a pure function of scroll progress near the edges plus intro progress, no tween-chain state machine; the 3D scene renders only when the viewport is near a desk zone (see ADR-0012).

## Update (2026-10-04, user iterate round)

WIDE is now ~45° elevation (was ~14° frontal) — the user found the flat angle artificial and asked for near-top-down with a hint of tilt kept; the scrub to PUSH becomes mostly a shortening dive, which also removes most of the "zoom jarring". The scrubbed camera is no longer a pure function applied directly: `setCam` writes a goal pose and the render loop chases it with frame-rate-independent damping (k = 1 − exp(−dt·12), ~63% in 80ms — tuned so random up/down wheel input produces smooth pursuit, never teleporting, without feeling soft; the intro dolly keeps `camDirect` for authored timing). Exposure is per-pose: 1.12 at PUSH, +0.18 rising toward WIDE — the desk shot was judged too dark while the read framing was fine (user), so the wide rides a brighter grade instead of flattening the whole scene. Handoff lands EXACTLY on the hero's snap point (hero-centered; the lead sigil cap fills the top of frame) and a `#hash` deep-link overrides that landing; a `tapestry:handoff` DOM event opens the reveal gate (ADR-0011 update).
